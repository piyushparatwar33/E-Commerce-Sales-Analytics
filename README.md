# E-Commerce Sales Analytics

## 📌 Project Overview
An end-to-end E-Commerce Sales Analytics project designed to demonstrate practical Data Analyst skills using **SQL, Python, Excel and Power BI**.

## 🎯 Business Objectives
- Track revenue, profit and order performance
- Identify top-performing products and categories
- Compare regional and customer-segment performance
- Analyze payment-method usage
- Find opportunities to improve profitability

## 🛠️ Tools & Technologies
- SQL
- Python (Pandas, NumPy, Matplotlib)
- Excel
- Power BI

## 📊 Dataset
The project uses a synthetic e-commerce dataset containing 1,000 orders with order date, customer, region, segment, product, category, quantity, pricing, discount, revenue, cost, profit and payment method.

## 🔎 Key KPIs
- Total Revenue
- Total Profit
- Total Orders
- Average Order Value
- Profit Margin
- Total Quantity Sold

## 🧠 SQL Analysis
The SQL script includes KPI calculations, monthly sales, category performance, regional performance, top products and customer-segment analysis.

## 🐍 Python Analysis
Python is used for data loading, validation, KPI calculation, aggregation and visualization-ready analysis.

## 💡 Business Recommendations
- Focus marketing on high-revenue/high-margin categories.
- Monitor products with strong sales but weak profit margins.
- Compare regional performance to identify expansion opportunities.
- Encourage high-value customer segments with targeted offers.
